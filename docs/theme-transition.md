# 1.2.4 主题过渡与分页流畅度

此前将所有 Tk/ttk 控件逐帧改色：日志标题、按钮栏、文本区等控件各自排队绘制，出现大面积矩形色带；只修正位图与原生颜色的取整差异不足以消除这个问题。每帧广播样式也会阻塞两个滑块。

1.2.4 在 Windows 上将主体的起点和终点各捕获一次，以两张完整画面交给 DWM 合成，逐帧只更新整体透明度。终点画面覆盖主体空隙和父容器背景，确保它们也参与同一过渡。顶部标题、版本号、主题按钮、分页按钮和原生标题栏保持实时更新，主体不再逐帧遍历控件或混合、复制整幅位图。

两个分段滑块保留可中断的临界阻尼运动，反向选择沿用当前位置及速度。帧调度按 60 Hz 预算扣除本帧绘制开销，动画期间请求 Windows 1 ms 定时精度，结束、取消、关闭时配对释放。准备画面所耗时间不计入第一步弹簧积分，避免起步跳动。大卡片只抗锯齿绘制小块圆角，再拼接平面，避免首次切页时逐像素建立调色板、缩放整幅大图。

合成表面是本程序拥有的原生窗口，不获取焦点、不接收鼠标。主体点击、键盘输入、滚动、焦点进入及分页切换会先完成主题过渡，再交给原生控件操作；文件路径、角度筛选、日志、滚动位置与处理进度保留。移动、缩放、最小化或关闭时释放表面。主题过渡期间后台日志仍记录到原控件，结束后显示最新内容；不逐帧重新捕获后台变化。

默认 Dark。系统关闭客户端区域动画或使用键盘选择时立即切换。捕获或原生合成失败时完成到目标主题，不残留覆盖层。DWM 标题栏背景和文字颜色随当前配色设置；不支持自定义颜色的旧 Windows 保留深浅两档降级。

## 验证与性能范围

Windows 11、150% 显示缩放、1049×674 客户区下，验证三页、双向切换、六个阶段，共 36 张真实屏幕截图。捕获包含原生合成表面，并与两端画面的预期混合逐像素比较，允许 Windows 混色取整的微小差别；同时检查原生标题栏颜色。检查覆盖整个主体，包括日志标题、按钮栏、卡片间隙和页脚。

实际 Tk 主事件循环测量中，主体及两个滑块帧间隔中位数约 17 ms。单次主题切换开始时仍需捕获和准备画面，本机约 50–100 ms；结果随显示缩放、显卡和系统负载变化，不能保证所有机器恒定 60 FPS。

自动测试覆盖原生表面的输入穿透、焦点和主窗口样式、输入前完成过渡、数据保留、快速反向复用、缩放/隐藏/关闭清理、原生 GDI/USER 句柄不累积、捕获及合成失败降级、定时精度释放和减少动态效果。
